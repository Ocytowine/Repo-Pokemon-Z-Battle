Titre : Fluidifier l'animation des sprites pendant le combat
Description : Les animations des sprites pendant le combat manquent de fluidité, ce qui nuit à l'expérience de jeu.
Idée d'amélioration :
1. Ajouter un systeme permettant de passer d'une image de sprite à une autre de manière fluide (en floutant la transition peut etre ?).
2. Utiliser des techniques d'animation par interpolation pour rendre les mouvements plus fluides.
3. Ajouter des effets de transition entre les différentes animations pour éviter les coupures abruptes.

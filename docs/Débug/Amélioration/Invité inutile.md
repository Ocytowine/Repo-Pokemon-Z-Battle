Titre : l'invité est inutile (à part pour les combats)
Description : il faut donner plus de fonctionnalités à l'invité en dehors des combats.
Idée d'amélioration :
1. L'invité peut parler avec les pnjs non lié à la narration, et avec les panneaux.
2. L'invité peut ramasser des objets non rares. (les objets sont envoyer dans le sac du joueur hote avec un petit message (nomdelinvite a ramassé l'objet))
3. L'invité peut participer à des mini-jeux ou des activités secondaires. (existant dans le jeu de base)
4. L'invité et l'hote peuvent intéragir entre eux pour échanger des objets ou discuter.
5. l'invité peut envoyer des emotes.
6. quand une demande est envoyé par l'invité, le joueur hote reçoit une notification pour accepter ou refuser la demande.

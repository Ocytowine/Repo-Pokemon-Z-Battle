# Comment faire du débogage dans Pokemon Z-Battle
## Remonter un bug

Pour remonter un bug dans Pokemon Z-Battle, suivez les étapes suivantes :

0. Jouer à la dernière version du jeu.
1. Décrivez le bug de manière claire et détaillée.
2. Indiquez les étapes pour reproduire le bug.
3. Publier le fichier dans le dossier Débug.
4. Probleme bloquant ? En parler à Emilien pour la suite
5. Probleme non bloquant ? Continuer à jouer et signaler si nécessaire.

### Exemple de rapport de bug

```
Titre : [Résumé concis du bug]
Description : [Description détaillée du bug]
Étapes pour reproduire :
1. [Première étape]
2. [Deuxième étape]
3. [Et ainsi de suite]
Résultat attendu : [Ce qui aurait dû se passer]
Résultat réel : [Ce qui s'est réellement passé]

```

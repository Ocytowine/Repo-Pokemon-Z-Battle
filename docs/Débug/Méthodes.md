# Comment faire du débogage dans Pokemon Z-Battle
## Remonter un bug

Pour remonter un bug dans Pokemon Z-Battle, suivez les étapes suivantes :

0. Jouer à la dernière version du jeu.
1. Un bug ? Est-il déjà connu ou documenté ? oui : voir si c'est une variante du bug existant, non : continuer.
2. Si le bug est nouveau, continuer avec les étapes suivantes.
3. Décrivez le bug de manière claire et détaillée.
4. Indiquez les étapes pour reproduire le bug.
5. Publier le fichier dans le dossier "Bug".
6. Probleme bloquant ? En parler à Emilien pour la suite
7. Probleme non bloquant ? Continuer à jouer et signaler si nécessaire.

### Exemple de rapport de bug

```
Titre : [Résumé concis du bug]
Description : [Description détaillée du bug]
Étapes pour reproduire :
1. [Première étape]
2. [Deuxième étape]
3. [Et ainsi de suite]
Résultat attendu : [Ce qui aurait dû se passer]
Résultat réel : [Ce qui s'est réellement passé]

```
## Remonter une amélioration

Quelque règle pour savoir si l'amélioration est pertinente :
1. L'amélioration doit apporter une réelle valeur ajoutée au jeu.
2. L'amélioration ne doit pas etre un raccourci d'une autre fonctionnalité existante.
3. L'amélioration doit etre facile à comprendre et à utiliser pour les joueurs.
4. Il faut que l'amélioration s'appuie sur une fonctionnalitée existante du jeu, ou prévue.

Pour faire remonter une amélioration, il faut utiliser le modèle suivant :

```
Titre : [Résumé concis de l'amélioration]
Description : [Description détaillée de l'amélioration]
Idée d'amélioration :
1. [Première étape]
2. [Deuxième étape]
3. [Et ainsi de suite]

```

# Game assets

Ce paquet contient les visuels versionnes propres aux interfaces de Pokemon
Z-Battle. Contrairement aux ressources du jeu source servies depuis `.pokemon-z`,
ces fichiers peuvent etre utilises par toutes les applications du monorepo.

Les 19 icones de types dans `assets/type-icons` ont ete importees le 2026-10-02
depuis le dossier local `Repo-KantoTeam/KantoTeam/appli pokemon/data`, a la demande
du porteur du projet. Les noms de fichiers anglais sont des identifiants techniques ;
les libelles affiches restent localises par le jeu.
